# 🏢 Employee Attrition Prediction using Machine Learning

## 📌 Project Overview

Employee Attrition Prediction is a Machine Learning web application that predicts whether an employee is likely to leave the company based on HR-related information.

The project uses a **Logistic Regression** model trained on the **IBM HR Analytics Employee Attrition Dataset** and is developed using **Python**, **Scikit-learn**, **Streamlit**, and **Plotly**.

Users can enter employee details through an interactive web interface and instantly receive the prediction along with the probability of employee attrition.

## 📊 Dataset

**Dataset:** IBM HR Analytics Employee Attrition Dataset

The dataset contains employee information such as:

- Age
- Daily Rate
- Distance From Home
- Department
- Education
- Job Role
- Monthly Income
- Job Satisfaction
- Work Life Balance
- Environment Satisfaction
- Total Working Years
- Overtime
- Marital Status

**Target Variable**

- Attrition = Yes
- Attrition = No

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Ashu89506/Employee-Attrition-Prediction.git
```

### Go to Project Folder

```bash
cd Employee-Attrition-Prediction
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Streamlit App

```bash
streamlit run app.py
```
